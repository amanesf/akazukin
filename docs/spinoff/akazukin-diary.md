# 企画説明の日記（下書き・2026-10-03）

新しいゲームを作り始めました。題名は『鋼桜奇譚　大正赤ずきん』です。

舞台は大正時代の日本。昔、おばあさんを狼から助け、狼を1匹残らず退治した猟師がいました。猟師はそれが縁でおばあさんと結婚し、今はもう亡くなっています。

ところがある晩、赤い月が裂けて、異界から狼たちが攻めてきます。狙いは、猟師が遺した家と一族。迎え撃つのは、孫娘の赤ずきんです。背中にはおじいさんが遺した狩りの道具の大砲、手には弓。見た目はかわいい大正の女学生ですが、狼から見れば一番怖い相手です。

ゲームは横向きのタワーディフェンスで、スマホの縦画面で遊びます。赤ずきんは左に陣取り、右から押し寄せる狼を撃ち落とします。武器を強くしながら、味方の番犬たちを呼んでにぎやかに戦い、最後まで守り切れば狼は絶滅、完全クリアです。

メインビジュアルは、桜と赤い月の下で大砲を一斉に撃つ瞬間にしました。続きはまた書きます。
